# Илья Макаров — портфолио

Статический сайт с проектами, профессиональными навыками, личными качествами и контактами.

## Содержание

- Шесть подробных кейсов и двенадцать проектов в архиве.
- Адаптивная вёрстка, анимация и режим уменьшенного движения.
- Контакт: [Telegram @duraceprog](https://t.me/duraceprog).

Обложки проектов представляют собой иллюстративные интерфейсы с условными данными. Описания относятся к реальным проектам.

## Файлы

- `index.html` — структура страницы и основные тексты.
- `main.js` — описания проектов и интерактивность.
- `styles.css`, `portfolio.css` — оформление и адаптивные стили.
- `hero-chrome-knot.png` — графика первого экрана.

Сборка, серверная часть и установка зависимостей не требуются. Все локальные ресурсы используют относительные пути.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем сохраните настройки. Файл `.nojekyll` включает публикацию статических файлов без обработки Jekyll.

После успешного развёртывания GitHub покажет адрес сайта в разделе Pages. Последующие коммиты в `main` будут автоматически обновлять сайт.

Документация: [публикация GitHub Pages из ветки](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

# Савва — портфолио

Персональный сайт независимого разработчика: backend, приложения, API и автоматизация.

## Содержание

- Шесть подробных кейсов и двенадцать проектов в архиве.
- Навыки, подход к работе и дополнительная информация.
- Адаптивное оформление, плавные анимации и режим уменьшенного движения.
- Контакт: [Telegram @favech](https://t.me/favech).

Обложки проектов — иллюстративные интерфейсы с условными данными. Описания относятся к реальным проектам.

## Файлы

- `index.html` — структура и основные тексты.
- `main.js` — данные проектов, модальные окна и интерактивность.
- `styles.css`, `portfolio.css` — оформление и адаптивные стили.

Сборка, серверная часть и установка зависимостей не требуются. Все локальные ресурсы используют относительные пути. Анимацию можно отключить на странице; системная настройка уменьшенного движения учитывается автоматически.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем сохраните. Файл `.nojekyll` включает публикацию без обработки Jekyll.

После первого развёртывания GitHub покажет адрес сайта в разделе Pages. Последующие коммиты в `main` автоматически обновляют опубликованную версию.
